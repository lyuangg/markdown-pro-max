隐私政策

Privacy Policy

最后更新日期：2026-07-20

Markdown Pro Max（以下简称"本扩展"）尊重并保护您的隐私。 本隐私政策说明了本扩展如何收集、使用和存储您的数据。

Markdown Pro Max ("the Extension") respects and protects your privacy. This Privacy Policy explains how the Extension collects, uses, and stores your data.

1. 数据收集范围 / Data Collection

本扩展不会将您的任何数据上传到外部服务器。所有数据仅存储在您的浏览器本地。

The Extension does not upload any of your data to external servers. All data is stored locally in your browser only.

1.1 我们存储的数据 / Data We Store

  • 用户偏好设置（通过 chrome.storage.sync）： 主题模式、代码高亮配色、Mermaid 图表主题、语言偏好、侧边栏折叠状态、 阅读进度条开关、撒花动画开关、字数统计开关、页面宽度、表格样式等设置。
    User preferences (via chrome.storage.sync): theme, code highlight scheme, Mermaid theme, language, sidebar state, progress bar toggle, confetti toggle, word count, page width, table style, etc.
  • 浏览历史（通过 chrome.storage.local）： 最近打开的 Markdown 文件的 URL 和标题，仅用于在扩展弹窗中展示"最近打开"列表。 此功能可在设置中关闭或清空。
    Browsing history (via chrome.storage.local): URLs and titles of recently opened Markdown files, used only to show a "Recent" list in the popup. This feature can be disabled or cleared in Settings.
  • 使用次数统计（通过 chrome.storage.sync）： 记录部分功能（如表格复制、图片查看、图表复制、文档导出等）的使用次数， 仅用于判断是否达到免费试用上限，不会包含您浏览的具体文件内容。
    Usage counters (via chrome.storage.sync): counts of feature usage (table copy, image view, chart copy, export, etc.), used only to track free trial limits. Does not include file contents you browse.
  • 支付状态（通过 chrome.storage.sync）： 存储付费标识，用于判断是否解锁专业版功能。不存储任何支付信息（如银行卡号、微信账号等）。
    Payment status (via chrome.storage.sync): stores a paid/unpaid flag to determine feature access. No payment details (bank cards, WeChat accounts, etc.) are stored.
  • 排除站点列表（通过 chrome.storage.sync）： 您选择不自动渲染 Markdown 的网站域名列表。
    Excluded sites (via chrome.storage.sync): list of website domains you choose to exclude from automatic Markdown rendering.

1.2 我们不收集的数据 / Data We DO NOT Collect

  • 您浏览的 Markdown 文件的内容
  • 个人信息（姓名、邮箱、地址等）
  • 浏览历史（除扩展弹窗中显示的 Markdown 文件列表外）
  • 任何可用于识别您个人身份的信息
  • The content of Markdown files you view
  • Personal information (name, email, address, etc.)
  • Browsing history (except the Markdown file list shown in the popup)
  • Any information that can personally identify you

2. 数据使用目的 / How We Use Data

所有存储的数据仅用于以下目的：

  • 在您下次打开扩展时记住您的主题、语言等偏好设置
  • 在弹窗中显示最近打开的文件，方便快速访问
  • 区分免费版与专业版的功能权限
  • 按您的设置排除特定网站不自动渲染

All stored data is used solely for:

  • Remembering your preferences (theme, language, etc.) across sessions
  • Showing recently opened files in the popup for quick access
  • Differentiating free vs. pro feature access
  • Excluding specific websites from auto-rendering per your settings

3. 数据共享与传输 / Data Sharing & Transfer

本扩展不会将您的数据出售、分享或传输给任何第三方。 由于所有数据均存储在本地浏览器中，开发者也无法访问您的数据。

The Extension does not sell, share, or transfer your data to any third party. Since all data is stored locally in your browser, the developer cannot access your data.

4. 数据安全 / Data Security

您的数据存储在浏览器的 Chrome Storage API 中，由 Chrome 浏览器本身提供安全保护。 本扩展不搭建服务器，不接收网络请求，不存在数据泄露到服务器的风险。

Your data is stored via Chrome's Storage API and protected by the Chrome browser itself. The Extension does not operate servers, does not make network requests for user data, and there is no risk of data leaking to external servers.

5. 您的控制权 / Your Control

您可以随时：

  • 在扩展设置页面关闭历史记录功能、清空所有历史记录
  • 在扩展设置页面关闭/开启各项功能
  • 通过 Chrome 的"扩展程序"页面清除扩展的存储数据
  • 卸载扩展，所有本地数据将被自动清除

You can at any time:

  • Disable history recording or clear all history in Settings
  • Toggle individual features on/off in Settings
  • Clear the Extension's storage via Chrome's Extensions page
  • Uninstall the Extension — all local data will be automatically removed

6. 支付相关 / Payment

本扩展的专业版升级通过扫码支付完成，支付过程由您自行操作， 本扩展不获取、不存储您的任何支付账户信息。 支付成功标识仅存储在您的浏览器本地。

支付完成后会打开一个外部网页（yuancoder.com）展示支付成功结果。 该网页使用了百度统计（Baidu Analytics）记录页面访问数据，与扩展本身独立。

The pro upgrade is completed via QR code payment operated by you. The Extension does not collect or store any payment account information. The payment status flag is stored only locally in your browser.

After payment, an external page (yuancoder.com) will open to confirm success. That page uses Baidu Analytics to track page visits, which is independent of the Extension.

7. 隐私政策更新 / Policy Updates

如果本隐私政策发生变更，更新后的版本将在本页面发布。 建议您定期查看本页面以了解最新信息。

If this Privacy Policy changes, the updated version will be posted on this page. You are advised to review this page periodically for any changes.
